# Lessons

_Durable "how this repo behaves" notes — build quirks, testing tricks,
toolchain gotchas. Captured at milestone end, harvested at plan time._

_One lesson per line. Current knowledge, not history: a lesson proven false
is **corrected in place** and marked (`(M07, corrected M11)`); git holds the
original. A lesson is **retired** — leaving no line behind — once a test
fails on the mistake it warns about, another tracking file's slot owns the
content, or a matured family graduates whole into a doctrine module._

_Hard cap: 50 lines._

## Lessons

- 2026-07-26 (M06, extended M61/M62/M64/M67, trimmed 2026-09-06): a vignette using a Suggests package needs `requireNamespace()` + `knitr::knit_exit()` for CRAN's noSuggests flavor. Inline `r` expressions run under chunk `eval = FALSE`, so prose reading a guarded object goes in a guarded `results = "asis"` chunk. A recommended package, or one in an Import's recursive closure, cannot be masked, so a masking criterion on it certifies nothing.
- 2026-07-26 (M07, extended M14/M159, trimmed 2026-09-03): a test that hand-rolls the code path it covers pins nothing. `local_mocked_bindings()` reaches a mirai daemon (`dispatch_folds()` sends its worker by name) but not a test helper; `rlang::local_bindings(.env = environment(<helper>))` can. `test_local()` and `test_check()` are different daemon paths (`prime_daemons()` is a no-op under the second), so run a harness on the failing path.
- 2026-07-27 (M12, extended M20/M23/M74, corrected M79, used M167): `rlang::hash()` differs across two identical constructions of a tidymodels object, so the fixture cache hashes a canonical form keyed on call, arguments and RNG state. A `memoised()` parallel fixture gets the serial value: build it inline and assert `last_dispatch()`. A cross-block hit needs the same RNG stream state, since recipe step ids draw from it.
- 2026-07-27 (M15, extended M16/M159, trimmed 2026-09-03): stopping mirai work. A console interrupt unwinds a blocked `collect_mirai()` and runs `on.exit()`. `stop_mirai()` cancels only on a dispatcher-backed pool and is inert on a resolved map, so an unconditional cancelling `on.exit()` is safe. Test with a real SIGINT from a detached `sh`; a `&` child of a non-interactive shell ignores SIGINT. `daemons(0)` orphans an outstanding task.
- 2026-07-27 (M14, corrected M16, extended M23/M57/M76/M118/M147, trimmed 2026-09-03): suite reporting. Time it with a `Reporter` subclass on `stderr()` (`HangTraceReporter`). A bare `Rscript` sets no `NOT_CRAN`; `setup-r` sets it true in CI. `check-r-package` sets `_R_CHECK_FORCE_SUGGESTS_` and `_R_CHECK_CRAN_INCOMING_` false. Use `SummaryReporter$new(max_reports = Inf)` for a mutation check and `TESTTHAT_PARALLEL=FALSE` for teardown output.
- 2026-07-27 (M16, extended M21/M31/M48/M72/M110, trimmed 2026-09-22): bounding every wait does not bound the suite. Sum declared bounds per file against the CI cap, from the `helper-time-budget.R` ledger. Size a job cap for the slowest cold install, or it kills the build before cache-save. Put the hang bound on the test step. Split a far-longer file and queue its parts in `start-first`. Before hunting a hang, read each leg's step time on `main`.
- 2026-07-27 (M13, extended M23/M26/M27/M79): measuring object size. `lobstr::obj_size()` counts shared content once, but `serialize()` writes each reference as a copy, so measure the serialized stream for anything crossing a process. A formula written inside a function drags its frame; one at top level does not. A stream differs across processes (pid in temp paths), so compare within a band. Figures: `references/mori-backend-assessment.md`.
- 2026-09-01 (M41, extended M65): a name already in use inside the package is where a new one collides. `summarize_folds()` gained `.eval_time`, and `autoplot(type = "performance")`, naming panels through it, aborted on a duplicated factor level; an exported `collect_inner_metrics()` would have shadowed an internal one. Before a shape change or a new export, grep every caller and holder of the name.
- 2026-09-02 (M50, extended M53/M58/M67/M79/M88/M153, consolidated M56, used M165): every push to a PR branch restarts its `pull_request` matrix, tracking-only commits included, so keep docs-only commits local while CI runs. `gh pr merge --delete-branch` deletes the local branch and its withheld commits. Run `air format --check` before pushing. Two dispatches on one ref share a concurrency group, so the second cancels the first.
- 2026-09-03 (M51, corrected M52/M80, extended M76/M79/M094/M113/M151): a CI leg's time moves with the runner more than the code (one head's ubuntu `testthat.R` read 25, 15 and 14 min). A CI-timing criterion binds the slowest leg's step against its cap on one run named by id; read attempts from `gh api .../runs/<id>/attempts/<n>/jobs`. Local runs drift, so measure a test cut's saving as its share of `[hang-trace]` block time within one CI run.
- 2026-09-06 (M68, used M164): tune 2.1.0's inner run errors on an `extract` that returns `NULL`, so an extract keyed to one engine (`coef()` on a ranger fit) fails every fold, and a serial-versus-parallel identity compares two all-failed runs; pick an extract every fixture engine answers. A fixture key hashes an `extract` closure with its environment, so build a helper's extract over `baseenv()` or the cache misses on every call.
- 2026-09-07 (M73, extended M107): `rlang::cnd_signal()` re-raises an edited condition with every field intact, where `rlang::abort()` on `conditionMessage()` drops `parent`, bullets and data fields. Under `R_KEEP_PKG_SOURCE=yes`, which the check workflows set (corrected M147), a frame's call carries a `srcref`, so `identical()` with a `substitute()`d call fails only in CI; compare calls with attributes removed.
- 2026-09-10 (M81, extended M84, corrected M86): `parse()` rewrites `x |> f()` into `f(x)`, so a check on piped example source walks `getParseData()`. A `man-roxygen/` template must open with a tag, so a shared example carries its own `@examplesIf` guard. `devtools::run_examples()` skips guarded examples inside `\donttest{}` and writes `Rplots.pdf` at the package root, which `check()` NOTEs.
- 2026-09-11 (M83): `cli_abort()` interpolates every message element, so a string built by `cli::format_inline()` and spliced in as `x = d` is parsed again, and a brace in a user value (a deparsed `{x * 2}`) raises `rlib_error_3_0` in place of the intended class; hand it over as a value, `x = "{d}"`.
- 2026-09-11 (M86, extended M89, used M165): a regex sweep that deletes backtick spans joins the words around them (`has \`x\` been` matches `has been`), so leave a placeholder (`benchmarks/sweep-prose.R` plain mode). A checker that finds prose by dropping lines can drop its whole domain (a comment whose closer never comes) and print clean over a page it no longer reads. Test each drop rule for what it takes with it.
- 2026-09-15 (M96, extended M97): roxygen splices a `@template`'s tags in, so a plain-text template cannot sit inside a section; one opening its own `@section` merges. `@templateVar` is block-scoped and last-wins across templates. A guarded brew tail ending a template breaks the paragraph when untailed prose follows. `tools::Rd2txt_options()` takes its bullet from the locale, so a test on rendered lists pins `itemBullet`.
- 2026-09-16 (M101, extended M106/M107, used M167): the hard-dependency Ubuntu CI leg installs no Suggests, but tune brings recipes and yardstick, so `skip_if_no_engines()` alone passes there and the test errors. A workflow-set test takes `skip_if_no_wset_fixture()`, a ranger fixture `skip_if_no_engines(stochastic = TRUE)`, and a racer or annealer refusal test skips where `tuner_ready()` is false. The full local suite exercises none of these.
- 2026-10-18 (M149, used M161): `devtools::check()` run inside a `git worktree` reports a NOTE on a hidden `.git`, because a worktree's `.git` is a file and the build skips only a `.git` folder; the same commit gave 0 notes in the main checkout. A worktree is a fine place to run `devtools::test()` beside ongoing edits, but take the gating `check()` from the main checkout.
- 2026-10-22 (M152, extended M158, used M167): pruning tests. A block filed as dependency behavior can hold the package's own part (no S3 method registered); keep it. A loop over both racers repeats only where it reads nothing from the racer's registry entry. Re-point `helper-time-budget.R` rows once per diff. `test-parallel-identity.R`'s shared pool can lose a daemon, mostly beside other R sessions, so run a gating suite alone (corrected M159).
- 2026-10-31 (M163, used M167): `cairn/ORACLES.md` upkeep. A test counts as named only when its record quotes the name; mark any other listed test "(found by reading)". A reference that runs the package's own function by hand is invariant, not live. A promise over prose judgment ("the tests a record names", "grouped by result") drew new findings on each of three review passes until it became a quoting rule and named groups.
- 2026-10-31 (M164, used M167): a planted defect proves a new check only if the fixture can show it. On `det_workflow()` a perturbed seed reaches nothing a map test compares, and rmse and rsq pick alike on the grid fixtures, so both plants passed while a one-candidate grid failed. An inner `vfold_cv()` split keeps an explicit `out_id`, so a row dropped from `in_id` leaves its assessment set as it was.
- 2026-10-31 (M164, used M167): testthat's `info =` takes a character value. A number raises an error only when the expectation fails, so a planted defect shows as that error and not as the failure under test. Write `info = paste(i)`.
- 2026-10-31 (M166, used M167): credit an oracle with a part only when its input can show a defect there. A probability average whose rows already sum to one, or a median of two values, passes a wrong branch. A weight-change invariant compares exactly only when the new total is a power-of-two multiple of the old, since tune divides each weight by the total. `devtools::document()` rewrites `Config/roxygen2/version` to the local roxygen2.
- 2026-10-31 (M165): to test R code inside a workflow file, read it out with `yaml::read_yaml()` and run it from a script file. An `Rscript -e '...'` check of a backslash-heavy `gsub()` escape printed `abc` for `a.b+c`, where the same line run from a file gave `a\.b\+c`. `git grep` has no `-x`, so a whole-line marker check uses plain `grep -lxF` on a checkout.
- 2026-10-31 (M167): plants a fixture hides. survreg's `.pred_time` rises with `.pred_linear_pred`, and the static and linear-predictor survival metrics score by rank, so swapping the two shows only once one is reordered (`reverse_pred()`). A ranger race does not reproduce on a cut inner design, since tune's seeds follow the design's size; `det_workflow()` does. `run_tuner()` resets the event level, so plant where the final fit reads it.
