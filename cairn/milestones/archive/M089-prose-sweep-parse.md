# M089: The prose sweep reads as prose only what its definition names

**Status:** done (2026-09-12, PR #102 https://github.com/tidymodels/nestedtune/pull/102)

**Goal:** `benchmarks/sweep-prose.R` reads as prose only what its stated definition names, so no badge, fence, comment or list-item line reaches a sweep.

**Outcome:** `rmd_paragraphs()` implements the partition the script header states. A badge line (`^\[!\[`) drops in every mode, the `badges` argument going with it and `--openings` losing its badge clause. A fence line matches with leading whitespace or without. An HTML comment drops from a line opening `<!--` through the line holding `-->`; an opener with no closer under it drops its own line alone, so a typo cannot empty a page of the prose a sweep reads. A list item, bulleted or numbered (`^\s*([-*]|[0-9]+\.) `), takes the lines it wraps onto up to the next blank line, and the loop skips lines already dropped, so an item-shaped line inside the YAML header or a fenced chunk opens no run. Over the six pages `--paragraphs` lists 122 paragraphs (README 3, parallel 10, estimate 25, nested-cv 29, results 31, tuners 24); crossed against the criterion's grep, 0 hold an excluded line and 0 open after an item, the nine paragraphs the branch point named gone. `tests/testthat/fixtures/sweep-prose-parse.Rmd` plants one leak per rule plus a marker straddling a backtick span; two `test_that()` blocks cover them, the second writing its pages in the test. No page prose changed: the six gating sweeps print `clean`, `devtools::test()` 9854, `devtools::check()` 0/0/0.

**Decisions:** none.

**Review:** three-lens fan-out. The blame-history and prior-review lenses found nothing; the diff-bug lens returned 11. Each of the two parse fixes was reverted in turn and the new block failed. Follow-up, on one candidate row: a loose list's continuation paragraph is swept, a comment opened partway leaks its body, a `2020. ` prose line is dropped as a numbered item, an indented fence inside a chunk can close it early, and the fixture's plant assertions are all negative. Rejected: setext headings and the first-two-`---` YAML rule, pre-existing at the branch point. No action: the lens's mid-review read of the milestone file, and a stale paragraph count in the RR07 archive (IP4). CI green on fourteen checks.
