**Status:** done (2026-09-07, PR #82 https://github.com/tidymodels/nestedtune/pull/82)

**Goal:** Give the three single-workflow readers a set method, so a user comparing workflows on one design reads each workflow's selections, fold spread and agreement table under its id without indexing `x$result`.

**Outcome:** `summary.nested_results_set()` (`R/nested-results-print.R`) loops `for_workflow()` over the elements, an all-failed one included, returning a `summary.nested_results_set` list named by `wflow_id` with the orchestrator as a `fn` attribute; `print_summary_sections(s, level)` is the single print's body factored so the set prints one h1, one h2 per workflow (h3 selection and estimate headings) and the IP3 note once. `autoplot.nested_results_set()` (`R/nested-results-plot.R`): `plot_set_performance()` stacks each workflow's `per_fold_metrics()` through `stack_set()`, workflows on x with levels from `x$wflow_id` and `drop = FALSE`, one panel per distinct metric key (`distinct_metric_keys()`), a dashed zero-height `geom_errorbar` at each workflow's mean, a subtitle line counting the workflows that did not complete every fold; `plot_set_selection()` pools every workflow's `selection_rows()` before `selection_axis()`, panels `"<id>: <label>"` in set order, `nestedtune_no_tuned_parameters` when none yields a frame. `agreement.nested_results_set()` (`R/nested-results-agreement.R`) stacks through `stack_set()` and reorders to `wflow_id`, parameters, `n`, `prop`. `stack_set()` gained `action`/`noun` words so the plot refusals share the collect path.
