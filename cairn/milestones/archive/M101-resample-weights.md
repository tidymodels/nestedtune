# M101: The outer average honors tune's resample weights

**Status:** done (2026-09-16, PR #114 https://github.com/tidymodels/nestedtune/pull/114)

**Goal:** A nested design carrying tune's `.resample_weights` attribute (set by `tune::add_resample_weights()`) yields a weighted outer average, with tune 2.1.0's weighted mean and standard error over the folds that scored.

**Outcome:** `new_nested_results()` records the design's `.resample_weights` as a `resample_weights` attribute, a table keyed by the fold label columns, carried by `stamp_results()` and listed in `run_attributes()`; absent on an unweighted design and on older records. `fold_weights()` reads each row's weight by label. `per_fold_metrics()` adds a `.weight` column on a weighted run, so `collect_metrics(summarize = FALSE)` and `compute_metrics()` carry it. `summarize_folds()` weights the mean with `stats::weighted.mean()` and the standard error with `weighted_std_err()`, the `cov.wt()` weighted standard deviation over the square root of `sum(w)^2 / sum(w^2)` floored at one, as tune's `estimate_tune_results()` does; a fold that fails or scores `NA` is dropped and the rest renormalize; scoring folds carrying zero weight between them read `NA`; `n` counts the folds that scored. `man-roxygen/section-resample-weights.R` sits on the five orchestrator pages; `?collect_metrics` names the weighted `std_err` and `.weight`. tune#1197 filed: tune's weighted branch errors on an `NA` estimate and drops the weights on a failed resample.

**Decisions:** the attribute is keyed by fold label rather than a `.weight` record column, so a reordered run keeps each fold's weight and the print is unchanged; the help states this package's `NA`-fold rule alone.
