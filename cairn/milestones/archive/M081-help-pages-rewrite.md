# M081: The help pages read for a tidymodels user: one-sentence arguments, shared text once, piped examples

**Status:** done (2026-09-10, PR #92 https://github.com/tidymodels/nestedtune/pull/92; resolves #91 partial)

**Goal:** Rewrite every help page so a tidymodels user meets one-sentence argument entries, a short description, details under their own headings, examples written with pipes, and none of the double hyphens, internal vocabulary or text pasted between files that issue #91 names.

**Outcome:** Every exported topic's roxygen rewritten (27 topics; 57 files, +3,964/−4,643). Argument entries capped at two sentences and 50 words (105 items, max 50 words), detail moved under `@section`s. The six orchestrator pages inherit shared arguments through `@inheritParams` from the wrapped tune, finetune or workflowsets function or from `nested_tune_grid`, and the siblings pull the Nested designs, Finalizing a parameter range and Evaluation times sections from `?nested_tune_grid` with `@inheritSection` where their signatures take the argument. Four `man-roxygen/` templates hold the `mtcars` example setup (with its own `@examplesIf` guard, `\donttest{}` dropped), three further example bodies and the orchestrators' Reproducibility section; the by-hand fold reproduction stays on `?nested_tune_grid`. No three-line prose window recurs across blocks (952 windows; 46 recurred at `c5638cf`). Every example uses `|>` and runs under check. `?nested_resamples` carries the README memory table, cited to `test-nested-resamples-memory.R`. `_pkgdown.yml` blurbs and a NEWS entry; `^man-roxygen$` in `.Rbuildignore`. Only `#'` lines changed under `R/`.

**Decisions:** the shared example setup is a template carrying its own `@examplesIf` guard, each page guarding its own lines, `\donttest{}` dropped since check runs those examples anyway; the IP3 paragraph is one plain paragraph on `?nested_tune_grid` and `?nested_final_fit`; the Reproducibility section is one template for the six orchestrators, the by-hand reproduction staying on `?nested_tune_grid` (a roxygen template must open with a tag, so no sentence-sized template).

**Review:** one defect return (AC2: a two-sentence `grid` override, and the section clause failing on `nested_fit_resamples` and `nested_workflow_map`) and one amendment return on AC2 (the section clause bound to each sibling's own signature, the check widened to every `@param` tag). Pass 2: three-lens fan-out, 15 findings, none a criterion failure. Fixed at the gate: the Bayes seed line and `param_info` in the by-hand recipe, the evaluation-times section inherited by the tuning siblings with a one-sentence `eval_time` override on `?nested_fit_resamples`, a local Bayes `iter` floor, two NEWS clauses, the Monte Carlo wording on `collect_predictions`, the print candidate-count condition, and the restored one-copy-per-fold payload sentence (PR #24). Rejected: the Bayes page keeping both finalizing sections (the return gate's choice), `allow_par` in the recipe, a design pointer on `nested_workflow_map`'s `...` (at AC1's cap), the `metrics` first-metric sentence, the `nestedtune_untuned_workflow` class name (on `?nested_fit_resamples`), and the parallel section's compressed rationale. Prior-review lens: no regression. Nothing graduated or retired.
