# M75: The suite makes each claim once, and the files that test the harness rather than the package are deleted or trimmed

**Status:** done (2026-09-08, PR #85 https://github.com/tidymodels/nestedtune/pull/85)

**Goal:** Delete test blocks whose claim a surviving block already asserts, and thin the nine files that test the harness, the CI yaml or the vignettes' citations rather than the package, so the suite reads as one check per claim.

**Outcome:** 795 to 755 `test_that()` blocks, 41 removed and 1 added, with no change to `R/`. Three files deleted whole — `test-vignette-citations.R`, `test-drift-manifest.R`, `helper-drift-manifest.R` — and three trimmed: four report blocks from `test-fixture-cache.R`, one fixture self-test from `test-hang-trace.R`, three duplicated blocks from `test-parallel-classify.R`. Eleven per-tuner duplicates folded into survivors that assert as much or more: the outer-columns trio into the two `test-nested-tune-grid-results.R` blocks, the failed-fold rng trio into `test-nested-tune-grid-rng.R` plus two zero-row oracles blocks (one added on the head for the race path), three `test-nested-final-fit-results.R` blocks into one cached fit, and three `test-parallel-classify.R` merges. The deduplication rests on one shared site: every orchestrator calls `nested_loop()`, and `control$save_pred` and `control$extract` are read only inside `nested_fold_fit()`. `expect_outer_columns_kept()` and `fixture_cache_reset()` removed as uncalled; the `helper-time-budget.R` ledger re-keyed to the moved `test-parallel-classify.R` lines. `test-suite-hygiene.R`, `test-ci-workflows.R`, `test-dots-barrier.R` and `test-control-slots.R` kept whole. The milestone file's Removals and File ledger tables are the per-block and per-file record; git holds them.

**Decisions:** none milestone-local. The 2026-09-08 question gate read `test-parallel-classify.R` as package tests rather than harness, deleted `test-vignette-citations.R`, and kept `test-ci-workflows.R` as the regression test of the pkgdown deploy hotfix (`7ca14b7`, PR #17).

**Review:** one defect return, then a clean pass. The first round failed AC1 — four deduplication rows removed a claim no survivor asserted (the `NAMESPACE` completeness tripwire, both by-hand-recipe blocks, the race path's failed-fold zero-row table) — and the repair restored those blocks and added one. Three amendment returns preceded it, on AC1 twice and AC2 twice. The second round's three-lens fan-out reported ten findings: two fixed on the branch (a stale Review section, a double blank line), two rejected (Scope naming families the repair restored; the final-fit merge costing failure granularity), one noted, and five filed — the citation guard, the wire-figure guard, `save_pred`/`extract` on the three non-grid tuners, the fixture-cache report, and the un-reordered `start-first` list. Nothing graduated or retired.
