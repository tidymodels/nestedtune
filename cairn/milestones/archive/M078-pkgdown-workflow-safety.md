# M078: The site build runs no repository code under a writable token, and the published site carries nothing the repository keeps to itself

**Status:** done (2026-09-10, PR #88 https://github.com/tidymodels/nestedtune/pull/88)

**Goal:** Nothing the repository keeps to itself is served from the published pkgdown site, and no repository code runs under a token that can write to the repository.

**Outcome:** `.github/workflows/pkgdown.yaml` regains the two-job shape `72c3be2` collapsed. `build` runs at the workflow's `read-all` and uploads `docs/` as an artifact; `deploy` holds `contents: write`, carries the job-level guard `github.ref_name == github.event.repository.default_branch`, and runs three steps that execute nothing checked out. Both jobs carry `timeout-minutes` (20/10); the deploy action stays SHA-pinned at v4.9.0. A `Drop the repo-internal sources` step deletes `CLAUDE.md` and `.github/ci-usage-baseline.md` before the build, since `pkgdown:::package_mds()` globs them into public pages with no config knob. A guard then iterates `git ls-files -- '*.md' '.github/*.md'` (145 sources) against the built site's root listing, `sitemap.xml` and `search.json`, allowing a page only for `README.md`, `NEWS.md`, `LICENSE.md`, `.github/CODE_OF_CONDUCT.md` and `.github/CONTRIBUTING.md`; `check_pkgdown()` and an advertised-pages guard flank it. Each guard was planted and seen red before being trusted. `extra-packages` returns to `local::.` alone, with `needs: website` resolving the builder from `Config/Needs/website`. `R-CMD-check-hard.yaml` gains the `paths-ignore` list, making eight identical copies across four workflows and `ci-usage.py` exit 0. Every departure from the r-lib stock template carries a comment naming what it buys. `CLAUDE.html`, `ci-usage-baseline.html` and their two markdown sources came off `gh-pages` by hand with their index entries: sitemap 46 -> 44 urls, search 273 -> 269 entries, all four paths now 404.

**Decisions:** kept the `release: published` trigger as a build-only check, a release run's ref being the tag while the publish guard names the default branch; took the two leaked markdown sources off `gh-pages` alongside their HTML. Scope was extended at a mini gate to `R-CMD-check-hard.yaml`'s two triggers. Cross-cutting: D-060.

**Review:** three-lens fan-out. Blame-history and prior-review found no defect. Diff-bug returned fourteen findings: six fixed at the gate — led by the artifact hop silently dropping `docs/.nojekyll`, which `upload-artifact` excludes as a dotfile and which no deploy the earlier two-job shape made ever carried, masked only by `clean: false` — plus three overstated prose claims and a stale copy count in three workflows; three routed to a new candidate row on the guard's coverage limits; five rejected, including the claim that `deploy` had never executed, refuted by the July `gh-pages` deploys. No acceptance criterion failed, so no return.
