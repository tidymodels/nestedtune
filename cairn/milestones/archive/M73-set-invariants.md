# M73: A `nested_results_set` keeps its class only while every row is one of the run's own workflows, and a re-signalled condition keeps its original's fields

**Status:** done (2026-09-07, PR #83 https://github.com/tidymodels/nestedtune/pull/83)

**Goal:** Make a subset of a workflow-set result answer only for the workflows it holds, so an operation that leaves rows that are not the run's own returns a plain tibble instead of an object still claiming the run, and make a condition re-signalled with a workflow's id keep the original's cause chain and fields.

**Outcome:** `R/nested-results-set.R` gains `can_reconstruct_set(data, template)`, `reconstruct_set()` and `bare_set()`, and five doors route to them — `dplyr_reconstruct.nested_results_set()`, `` `[.nested_results_set` ``, `vec_restore.nested_results_set()`, `rbind.nested_results_set()`, `` `names<-.nested_results_set` ``: the class and `fn` attribute stay while the result holds the three record columns unrepeated, at least one row, no repeated `wflow_id`, each row's three values identical to the first argument's row of that id, and the template itself a set; otherwise a bare tibble with `fn` dropped. No `vec_ptype2`/`vec_cast` lattice: a set with a bare table sheds through both doors and `vctrs::vec_cbind()` gives a tibble (candidate row). The readers, `summary()`, `print()`, `extract_workflow()` and `nested_final_fit()` answer on a kept subset for its rows; the union-bound readers hold the kept workflows' parameter columns. `resignal_for_workflow()` (`R/nested-workflow-map.R`) re-raises the original condition with `rlang::cnd_signal()`, `Workflow "<id>": ` prefixed to the first message line (an empty or missing message becoming the prefix alone), `call` through `rlang::error_call()`. Tests: `test-nested-results-set-compat.R` (44 doors), AC2/AC3 subsets and print snapshots in `test-nested-workflow-map-readers.R`, seven planted forms in `test-nested-workflow-map-checks.R`; the four set doors in the dots-barrier exemption list.
