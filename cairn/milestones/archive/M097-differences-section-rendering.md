# M097: The Differences sections render each heading's paragraph whole and one list per page

**Status:** done (2026-09-15, PR #110 https://github.com/tidymodels/nestedtune/pull/110)

**Goal:** On the grid, bayes, race and sim-anneal help pages, the "Differences from calling ... directly" section renders every sentence inside the paragraph of the run-in heading it continues, renders the "Passed through" slots as one list followed by prose, and keeps each shared text in one `man-roxygen/` template.

**Outcome:** `man-roxygen/differences-forced.R` and `differences-settable.R` end in a guarded brew line that prints `FORCED_TAIL` or `SETTABLE_TAIL` when the page sets it. The four pages set their tail through `@templateVar` and drop the `@section` re-open lines the orphan sentences needed. `differences-passed-shared.R` is a closing paragraph after each page's own Passed-through list. So bayes, race and sim-anneal hold one `\itemize` each, and grid holds none. `tests/testthat/test-help-structure.R` renders the four pages with `tools::Rd2txt()`, with the bullet pinned to U+2022 and the output to UTF-8, and asserts the paragraph and list structure. It fails ten times against the pre-change pages. Only the four Rd pages changed under `man/`.

**Decisions:** none beyond the plan gate's, which the work log holds. They are a closing paragraph rather than bullets through a template variable, an inline brew expression on a `#'` line, a testthat file rather than a sweep mode, and the doubled blank lines out of scope.
