# M124: Averaged out-of-fold predictions

**Status:** done (2026-09-28, PR #139 https://github.com/tidymodels/nestedtune/pull/139)

**Goal:** A user reads one averaged out-of-fold prediction per data row from a nested run through `collect_predictions(summarize = TRUE)`, averaged by tune's rules.

**Outcome:** `collect_predictions()` on a `nested_results` and a `nested_results_set` takes `summarize = FALSE`. With `TRUE`, `average_fold_predictions()` in `R/nested-results-collect.R` gives one row per `.row` that a completed fold held out, in `.row` order. It drops the fold labels and `.config`. The set method passes `summarize` through `stack_set()`. The rule for each column is read from the saved columns. Numeric columns take the mean with missing values ignored. Probabilities are averaged and renormalized, and `class_from_probs()` recomputes the class, ordered as the outcome is. `class_by_vote()` takes the most frequent class and counts a missing vote as a class. `average_survival()` takes per-`.eval_time` means, and `.pred_time` takes the median. Ties go to the first level. `check_no_quantile()` refuses `.pred_quantile` with class `nestedtune_summarize_quantile`. A partial run warns once. The help section "Averaging across the folds", an executed example and a `NEWS.md` bullet state it. `tests/testthat/test-collect-predictions-summarize.R` compares the average with `tune::collect_predictions(summarize = TRUE)` for four run types. It also compares it with a base R average on grid runs whose repeats selected different candidates.

**Decisions:** D-090 extends D-054 with the argument. D-091 corrects D-090 in two places. The quantile refusal rests on the quantreg dependency that a check needs. A row with missing averaged probabilities gets a missing class, where tune gives the first level.

**Review:** Three fresh reviewers found no failing criterion. At the gate, O3 was fixed with a test that failed first. The class had taken its orderedness from the saved class, not the outcome. O8 reworded the NEWS bullet. O1, O2, O5, O6, S2 and part of O7 went to one candidate row. It covers empty censored lists, no single factor outcome, no row-match check, speed, and untested paths. O4, O9, O10 and S1 were rejected. The first CI run failed `format-suggest` on test-file wrapping, which the M50 lesson already covers. `air format` fixed it. A timed-out CI wait resumed and merged on 14 green checks. `devtools::check()` gave 0 errors, 0 warnings and 0 notes.
